Dr. Youssef Sbera — Demo Website
=================================

Files:
- index.html   → the full bilingual (EN/AR) demo website. Self-contained (images are embedded), so it works by itself — just open it in a browser or upload it as-is to GitHub Pages.
- /assets/     → the individual images used in the site, provided separately in case you want to replace them with higher-resolution originals from the doctor later.

To publish on GitHub Pages:
1. Create a new repository.
2. Upload index.html (keep the name "index.html").
3. Optionally upload the /assets folder too (not required — the page already has the images embedded inside index.html).
4. In the repo: Settings > Pages > set source to your main branch, root folder.
5. Your site will be live at: https://<your-username>.github.io/<repo-name>/

فایل index.html کامل و مستقل است — عکس‌ها از قبل داخلش جاسازی شده‌اند، پس همین یک فایل برای آپلود کافیست.
پوشه assets فقط برای مرجع است، اگر بعداً خواستی عکس‌های با کیفیت‌تر را جایگزین کنی.
